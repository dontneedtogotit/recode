# recode P0 GUI Sweep Implementation Plan

> **For Hermes:** Execute task-by-task with focused regression tests. Preserve the existing Tauri/React architecture and do not broaden into the deferred GUI roadmap.

**Goal:** Fix the fifteen P0 latent GUI defects catalogued in `GUI-IMPROVEMENTS.md`, including correct typed agent IPC, real keyboard palette behavior, live run output, cancellation, dynamic theme accents, input validation, and frontend regression coverage.

**Architecture:** Keep `App` as the owner of shared run/panel/console state. Centralize Tauri command adapters in `src/lib/ipc.ts`; expose one canonical navigation registry from `AppShell`; make the Rust pipeline emit a single structured `pipeline-event` payload and honor a run-scoped cancellation token. Add focused Vitest tests beside the frontend modules and Rust unit tests beside the pipeline modules.

**Tech Stack:** React 19, TypeScript, Vite, Vitest, Testing Library, jsdom, Tauri 2, Rust, serde.
